              <h2 id="msc-setup-section-1">
                #text "1. Terms and Definitions"
              </h2>
              #text "\n    "
              <p>
                #text "NINTENDO WFC: Nintendo's original online service for Nintendo Wii and DS games. It was terminated in 2014."
              </p>
              #text "\n    "
              <p>
                #text "WIIMMFI: A community-run online service that replaces Nintendo WFC for supported games."
              </p>
              #text "\n    "
              <p>
                #text "DOLPHIN: An emulator for Nintendo GameCube and Wii games that can run on PC."
              </p>
              #text "\n    "
              <p>
                #text "NETPLAY: A Dolphin feature that lets players host or join an online room using a shared code."
              </p>
              #text "\n    "
              <p>
                #text "HOMEBREW: Unofficial software/tools for Wii or Wii U, commonly used to run apps and game loaders (for example USB Loader GX)."
              </p>
              #text "\n    "
              <p>
                #text "WI-FI (WLAN): A wireless local network connection used by devices to connect to a router without a cable."
              </p>
              #text "\n    "
              <p>
                #text "ROUTER: The network device in your home that connects your devices to the internet (often your Wi-Fi box)."
              </p>
              #text "\n    "
              <p>
                #text "ETHERNET: A wired network connection standard (LAN). In this guide, it means using a cable instead of Wi-Fi for a more stable connection."
              </p>
              #text "\n    "
              <p>
                #text "MOBILE ROUTER OR HOTSPOT: A phone or mobile device feature that shares mobile data as a Wi-Fi network."
              </p>
              #text "\n    "
              <p>
                #text "SSID: The name of a Wi-Fi network."
              </p>
              #text "\n    "
              <p>
                #text "DNS: Domain Name System. In this context, custom DNS settings can redirect game network requests from Nintendo WFC endpoints to Wiimmfi endpoints."
              </p>
              #text "\n    "
              <p>
                #text "REGION-LOCK: A restriction where games/services only connect between matching regions. For MARIO STRIKERS CHARGED online, players must use the same game region."
              </p>
              #text "\n    "
              <p>
                #text "PORT: A network endpoint used by apps/services to send and receive traffic. If required ports are blocked, online services may fail to connect."
              </p>
              #text "\n    "
              <p>
                #text "FIREWALL: A security system that filters incoming and outgoing network traffic based on rules. You may need to allow Dolphin through your firewall for online play."
              </p>
              #text "\n    "
              <p class="cr-note">
                #text "Choose your path: use Section 2 for Wii setup or Section 3 for Dolphin setup."
              </p>

              <h2 id="msc-setup-section-2">
                #text "2. A: Wii/Wii U Setup"
              </h2>
              #text "\n    "
              <p>
                #text "Requirements:"
              </p>
              #text "\n    "
              <p>
                #text "Wii or Wii U with vWii mode (eShop game version is not supported)"
              </p>
              #text "\n    "
              <p>
                #text "A copy of MARIO STRIKERS CHARGED"
              </p>
              #text "\n    "
              <p>
                #text "Homebrew (loads the game through USB/SD card) or the DNS method (loads the game directly from the disc for a non-modded console)"
              </p>
              #text "\n    "
              <h3>
                #text "2.1 Homebrew Method"
              </h3>
              #text "\n    "
              <p>
                #text "The Homebrew method lets you mod your Wii or Wii U console. This allows you to launch MARIO STRIKERS CHARGED, cross-play with Dolphin users, and play without a physical copy through a USB loader."
              </p>
              #text "\n    "
              <p>
                #text "Follow these links if you cannot use a valid copy or if you need cross-play with the PAL version of the game (competitions use the PAL version, and Homebrew allows region loading on NTSC consoles):"
              </p>
              #text "\n    "
              <p>
                #text "Homebrew Wii: "
                <a class="cr-link" href="https://wii.guide/" target="_blank" rel="noopener noreferrer">
                  #text "Wii Guide"
                </a>
              </p>
              #text "\n    "
              <p>
                #text "Homebrew Wii U: "
                <a class="cr-link" href="https://wiiu.hacks.guide/#/introduction" target="_blank" rel="noopener noreferrer">
                  #text "Wii U Hacks Guide"
                </a>
              </p>
              #text "\n    "
              <h3>
                #text "2.2 DNS Method (Wii Only)"
              </h3>
              #text "\n    "
              <p>
                #text "This DNS method is supported on Nintendo Wii only and is not supported on Wii U."
              </p>
              #text "\n    "
              <p>
                #text "To use Wiimmfi (required for non-modded Wii online play in MARIO STRIKERS CHARGED), configure your Wii internet DNS settings as follows:"
              </p>
              #text "\n    "
              <ol>
                #text "\n    "
                <li>
                  #text "Go into your Wii Options"
                </li>
                #text "\n    "
                <li>
                  #text "Wii Settings > Page 2"
                </li>
                #text "\n    "
                <li>
                  #text "Internet"
                </li>
                #text "\n    "
                <li>
                  #text "Connection Settings"
                </li>
                #text "\n    "
                <li>
                  #text "Select your active Connection from the list"
                </li>
                #text "\n    "
                <li>
                  #text "Change settings"
                </li>
                #text "\n    "
                <li>
                  #text "Click the right arrow button until you reach the screen where you can change DNS settings"
                </li>
                #text "\n    "
                <li>
                  #text "Select No and then Advanced Settings"
                </li>
                #text "\n    "
                <li>
                  #text "Set Primary DNS to 95.217.77.181 and Secondary DNS to 8.8.8.8"
                </li>
                #text "\n    "
                <li>
                  #text "Confirm and start a Connection Test"
                </li>
                #text "\n    "
                <li>
                  #text "If the connection test fails, make sure your Wii has Internet access and double-check your settings (see Section 5.1)."
                </li>
                #text "\n    "
              </ol>
              #text "\n    "

              </figure>
              #text "\n    "
              <h4>
                #text "2.3.2 Latency and Speed"
              </h4>
              #text "\n    "
              <p>
                #text "For online play, stability matters more than raw internet speed."
              </p>
              #text "\n    "
              <p class="setup-guide-warning">
                <img class="setup-guide-warning-icon" src="/assets/text-boxes/ex-mark.png" width="35" height="100" alt="Warning"/>
                #text "Download/upload speed is not the main factor for match quality. Ping is the most important factor."
              </p>
              #text "\n    "
              <ul class="cr-list">
                #text "\n    "
                <li>
                  #text "What is ping?"
                </li>
                #text "\n    "
              </ul>
              #text "\n    "
              <p>
                #text "Ping is the delay between your input and the game response. Lower ping means smoother control."
              </p>
              #text "\n    "
              <ul class="cr-list">
                #text "\n    "
                <li>
                  #text "What ping is good?"
                </li>
                #text "\n    "
              </ul>
              #text "\n    "
              <p>
                #text "40-60 ms or lower is a good competitive target. Under 30 ms is ideal. Above 100 ms causes clear delay, and above 170 ms some matches may fail to connect."
              </p>
              #text "\n    "
              <p>
                #text "Example: 10 ms usually feels much smoother than 100 ms."
              </p>
              #text "\n    "
              <ul class="cr-list">
                #text "\n    "
                <li>
                  #text "What is lag?"
                </li>
                #text "\n    "
              </ul>
              #text "\n    "
              <p>
                #text "Lag means delayed or unstable gameplay. Inputs can feel late, the game may freeze briefly, then catch up, or disconnect."
              </p>
              #text "\n    "
              <h4>
                #text "2.3.3 Ping Optimization"
              </h4>
              #text "\n    "
              <ol>
                #text "\n    "
                <li>
                  #text "Check your ping before playing. Wii ping is often higher than PC ping."
                  <br/>
                  #text "\n    "
                  <a class="cr-link" href="http://www.speedtest.net/" target="_blank" rel="noopener noreferrer">
                    #text "OOKLA SPEEDTEST"
                  </a>
                  <br/>
                  #text "\n    "
                  <a class="cr-link" href="http://internethealthtest.org/" target="_blank" rel="noopener noreferrer">
                    #text "INTERNET HEALTH TEST"
                  </a>
                  <br/>
                  #text "\n    "
                  <a class="cr-link" href="https://speedof.me/" target="_blank" rel="noopener noreferrer">
                    #text "SPEEDOF.ME"
                  </a>
                </li>
                #text "\n    "
                <li>
                  #text "If you use Wi-Fi, stay close to your router."
                </li>
                #text "\n    "
                <li>
                  #text "Use a wired connection when possible (Wii LAN Adapter)."
                </li>
                #text "\n    "
                <li>
                  #text "A powerline adapter can improve connection stability."
                </li>
                #text "\n    "
                <li>
                  #text "During matches, avoid heavy network use (YouTube, Netflix, Twitch, large downloads)."
                </li>
                #text "\n    "
                <li>
                  #text "Disconnect unused devices from your network when possible."
                </li>
                #text "\n    "
                <li>
                  #text "If available, use fiber or a higher-quality internet plan."
                </li>
                #text "\n    "
                <li>
                  #text "If issues continue, check for outages with your internet provider."
                </li>
                #text "\n    "
                <li>
                  #text "Advanced users: prioritize your Wii or Wii U in router settings (QoS/device priority)."
                </li>
                #text "\n    "
              </ol>

              </h3>
              #text "\n    "
              <p>
                <a class="cr-link" href="https://dolphin-emu.org/download/?ref=btn" target="_blank" rel="noopener noreferrer">

                    #text "a"

                </a>
                #text " or newer"
              </p>
              #text "\n    "
              <p>
                #text "Requirements:"
              </p>

                  #text "MARIO STRIKERS CHARGED (R4QP01) game file (ISO, WBFS, RVZ, ...). NKit should be avoided whenever possible."
                </li>
                #text "\n    "
                <li>
                  #text "A NAND backup for Dolphin Wiimmfi to enable cross-play with Wii players (see Section 3.4.1)."
                </li>
                #text "\n    "
                <li>
                  #text "Any controller or Wii Remote with MotionPlus (emulates an IR pointer through motion sensors)."
                </li>
                #text "\n    "
                <li>
                  #text "A computer/laptop with Bluetooth or a Bluetooth USB dongle (for wireless controllers)."
                </li>
                #text "\n    "
                <li>
                  <a class="cr-link" href="https://drive.google.com/file/d/10WiwobQaAyv__KCLKtbW3CYtlMDa4Qzq/view?usp=sharing" target="_blank" rel="noopener noreferrer">

                  </a>
                  #text " or "
                  <a class="cr-link" href="https://drive.google.com/file/d/10X8IYytPqs2lUQX5AcRalLRIhdq5pbmM/view?usp=sharing" target="_blank" rel="noopener noreferrer">
                    #text "Customizable Profile with Mouse Used as IR Pointer"
                  </a>
                  #text "."
                </li>
                #text "\n    "
                <li>
                  <strong>
                    #text "Recommended PC Specifications"
                  </strong>
                  <br/>
                  #text "OS: Windows 11"
                  <br/>
                  #text "CPU: Intel Core i5 or better"
                  <br/>
                  #text "GPU: Intel HD 520 / NVIDIA GTX 950 / AMD Radeon RX 470 or better"
                  <br/>
                  #text "Memory: 8GB"
                  <br/>
                  <span class="setup-guide-note">
                    #text "*Windows 10 is no longer recommended because Microsoft support has ended."
                  </span>
                </li>
                #text "\n    "
              </ul>
