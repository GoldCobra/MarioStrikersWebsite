The Super Mario Strikers (Mario Smash Football) Competitive Ruleset

Last revised: March 14, 2024

1. Introduction

These rules establish a Competition Committee and define a standardized competitive ruleset.

2. Gameplay Settings

2.1 Gameplay

2.1.1 Game Version

The official tournament version is NTSC-U for Nintendo GameCube on the custom Citrus Dolphin build. The required game file format is .iso.

The Citrus build can be downloaded here: Citrus Build Download.

If a player has issues with Citrus, the latest Dolphin Beta can be used as a backup: Dolphin Download.

2.1.2 Dolphin Netplay Settings

  • The "Network" configuration in the Netplay lobby must be set to "Fair Input Delay".
  • Wired Ethernet is strongly encouraged for best gameplay quality, although not mandatory.
  • Players should agree on a stable buffer and generally use the lowest value that avoids lag.
  • A baseline formula is BUFFER = PING / 8, but values may be lower or higher if both players agree.
  • The absolute minimum buffer is 6, and the absolute maximum buffer is 20.
  • If no stable connection is possible at buffer 20 or lower, the match should be postponed.

2.1.3 Hosting

Before each set, players must determine the host through open discussion. The following scenarios apply:

  1. If neither player has a hosting preference, either player may host.
  2. If only one player prefers to host and the opponent has no preference, that player may host if the opponent agrees.
  3. If both players prefer a neutral host, a geographically reasonable host approved by MSL Staff may host if both players agree.
  4. If both players prefer to host or cannot agree, hosting rights are decided by a separate coin toss.
  • Once a host is chosen, that player hosts the full set unless the session is unstable and both players agree to change host. If disputed, involve MSL Staff immediately.
  • For multi-set scenarios (for example World Championship playoff sets or bracket resets), players may change hosts between sets. If a deciding set host is disputed, use another coin toss.

2.1.4 Lag

If connection quality is in doubt, players should test in Strikers 101 before starting the first match. Once both players agree that buffer and stability are acceptable, the set may begin.

  • If players cannot agree on buffer or connection stability during testing, contact MSL Staff before starting. If no staff is available, postpone the set.
  • After both players agree before the match starts, no one should pause during active gameplay unless there is a major connection change.
  • If a pause is necessary, wait until your own Kritter has full possession or immediately after a goal.
  • After pausing, players should discuss next steps (for example buffer changes or waiting for a spike to pass).
  • If players cannot agree, involve MSL Staff immediately. If no staff is available, record exact match details and pause the set until staff can resolve the issue.
  • Pressuring an opponent to continue under disputed connection conditions may result in penalties.

2.1.5 Match Settings

  • Skill Level: LEGEND
  • Match Time: 5 MINUTES
  • Power Ups: ON
  • Super Strikes: OFF
  • Rumble: ON
  • Bowser Attack: OFF

2.1.6 In-Game Visual Options

These are the default visual settings. If both players agree, zoom can be changed, but aspect ratio cannot be changed.

  • Camera Type: AUTO ZOOM
  • Aspect Ratio: WIDE (16:9)

2.1.7 Stadium List

  • Any stadium is allowed.

2.1.8 Match Procedure

The following process applies to best-of-3, best-of-5, and best-of-7 formats:

  • In bracket play, the higher seed gets first choice. In formats such as round robin or Swiss, a coin flip decides first choice.
  • The winner of first choice selects one option: stadium, home/away side, or first captain pick.
  • The other player selects one of the remaining two options, and the last option goes to the first player.
  • The game is played in the selected stadium with the selected side/captain setup.
  • After each game, the loser chooses two options from stadium, home/away side, and captain, and the winner gets the remaining option.
  • The player selecting stadium cannot choose a stadium they already won on earlier in the set unless both players agree.
  • This restriction applies even when that prior stadium win happened on the opponent's stadium choice.
  • If setup is incorrect (for example illegal stadium pick), players must quit within the first 5 seconds on the game timer; otherwise the game stands.

2.2 Prohibited Techniques and Selections

2.2.1 Super Team

Super Team is fully banned due to a slight run-speed advantage. Character information is available here: Character Information.

2.2.2 Cheat Codes

Cheat codes are strictly forbidden, including codes that do not directly affect gameplay.

2.3 Match Disruptions

2.3.1 Disconnections

Disconnecting during a game (for example rage quit) results in an automatic loss of that game. Because intent cannot always be proven, unintentional cases are handled through game recreation.

2.3.1.1 Restarting After Disconnection

If no player agreement is reached, restart the game as close as possible to the original state:

  • Score: Recreate score differential (for example crash at 7-4 -> recreate as 3-0).
  • Items: Match prior item state exactly, match item differential, or agree to restart with no items.
  • Time and possession: If one player had possession, that player walks the ball into goalie at the correct time and play continues. If possession was contested, walk to goalie and punt with B to resume neutral play.

2.3.2 Multiple Crashes or Disconnections

For repeated disconnections, the set should be rescheduled once the issue is resolved. Tournament organizers may forfeit a game at their discretion.

2.3.3 Stalling

Stalling or excessive delay may result in game or set forfeiture at organizer discretion. Stalling includes possession patterns with no counterplay and no offensive intent.

The core definition is subjective ("I know it when I see it"), but explicit examples are listed below.

2.3.3.1 Examples of Illegal Stalling Tactics

  • Standing still in front of your Kritter with the ball.
  • Dribbling away from the opponent's goal with no defensive pressure and no offensive intent.
  • Running kickoff possession back to your own defensive corner.
  • Running back to your Kritter unless one of the following applies: Kritter is stunned/recovering, Kritter is out of position, you are avoiding an incoming item, or you just collected the ball in your defensive corner.

2.3.3.2 Examples of Legal Time-Wasting Plays

  • Holding possession with Kritter as long as possible.
  • Clearing the ball downfield with a player or Kritter from any location, including kickoff.
  • Guarding a loose ball by hitting opposing players attempting to challenge.

2.3.3.3 Stalling Accusations

If a player (not a viewer) believes the opponent is stalling, finish the current game, then pause the set and follow this process:

  • Formally call "stalling." Without an official call, MSL Staff takes no action.
  • Provide video evidence (Citrus replay, player clip, or viewing-party clip). Without evidence, no staff action is possible.
  • At least one MSL Staff member reviews evidence and issues an official ruling.
  • If no staff is available, discontinue the set until review is possible.
  • If players continue without an official ruling, MSL Staff cannot retroactively alter match or set results.
  • After ruling, resume the set under normal MSL rules.

2.3.4 Game Disruptions

If a game uses misconfigured settings that could materially affect the result, a player may request a replay. Organizers decide final outcome. Requests must be immediate; once the next game starts, the prior game is locked.

2.3.5 Pausing Mid-Game

Mid-game pausing is not allowed except in limited circumstances and only in non-contested states (for example post-goal cutscene or ball secured by Kritter).

Accepted circumstances:

  • Urgent technical issues (for example ping spikes, wrong settings, controller failures).
  • Real-life emergencies.

Any unauthorized pause during active gameplay is an automatic game forfeit unless both players agree on a resolution or a true emergency applies.

  • Pauses should not exceed 1 minute unless active discussion with MSL Staff is ongoing.
  • If players cannot agree after 1 minute, contact MSL Staff immediately.
  • If no staff is available, record exact details and postpone until staff review.

All other pauses (including rage pauses or stat checks) are reviewable and may result in forfeits or additional penalties.

2.3.6 Penalties

Rules violations are subject to penalties including, but not limited to:

  • Game restart
  • Loss of a game
  • Loss of a match
  • Tournament forfeiture

Any penalty imposed on a player may be made public at organizer discretion.

2.4 Scheduling

2.4.1 Scheduling Expectations

Scheduling with your opponent is a core part of MSL and tournament play. Communicate early and often.

  • Players have real-life responsibilities; scheduled set times should be respected.
  • If you cannot make a scheduled time, notify your opponent as early as possible.

2.4.2 Penalties for Delays or Absences

When a date and time are mutually agreed for an MSL-related set, late arrival or no-show without communication triggers the following penalties:

  • 0-10 minutes late: No penalty
  • 10-20 minutes late: Loss of 1 pick (opponent gets first two picks in Game 1 setup)
  • 20-40 minutes late: Forfeit of Game 1
  • 40-60 minutes late: Forfeit of Games 1 and 2
  • More than 60 minutes late or no-show: Forfeit of the set

2.4.3 Emergency Clause

MSL Staff may rescind penalties and allow rescheduling when a player has a valid emergency reason for missing or being late without prior communication.

Abuse of this clause is prohibited. Repeated emergency claims may be denied at staff discretion.

2.4.4 Pressuring

Set times must be mutually agreed. Short-notice play is allowed only if both players agree.

Players must not pressure opponents into playing. Staff may penalize pressuring behavior.

Examples include, but are not limited to:

  • Excessive pinging.
  • Demanding immediate play by claiming your schedule otherwise cannot meet the deadline.

3. Code of Conduct

All players are expected to exhibit good sportsmanship and maintain respect for one another and for all tournament organizers. Players are expected to play at their best at all times and avoid behavior inconsistent with good sportsmanship, honesty, and fair play. Behavior considered inappropriate includes, but is not limited to:

  • Interfering with tournament operation
  • Acting in an unsportsmanlike or disruptive manner, or annoying, abusing, threatening, or harassing others
  • Engaging in collusion (for example any agreement to predetermine outcomes)
  • Cheating by any means
  • Intentionally delaying or tampering with gameplay
  • Offensive, vulgar, or obscene gamertags
  • Sexism, ageism, racism, or any other form of prejudice or bigotry
  • Engaging in violence or behavior deemed immoral, unethical, disgraceful, or indecent by tournament owners
  • Offering gifts or rewards to gain competitive advantage or create competitive disadvantage for opponents
  • Otherwise violating these rules
